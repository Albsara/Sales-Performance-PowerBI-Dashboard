# Sales Performance Power BI Dashboard

## Overview
An interactive Power BI dashboard developed to analyze sales performance and provide a clear view of key business metrics.

## Key Metrics
- Total Sales
- Total Profit
- Total Units Sold

## Dashboard Features
- Monthly sales trend analysis
- Sales performance by product
- Sales distribution by customer segment
- Country slicer for interactive filtering
- KPI cards for key performance indicators

## Tools & Skills
- Power BI Desktop
- DAX Measures
- Data Visualization
- Interactive Filtering
- Dashboard Design

## DAX Measures
- Total Sales
- Total Profit
- Total Units Sold
